# Collectedge Landing Page

Responsive clone of the Collectedge Figma design, built with **React + Vite + CSS Modules** for the Kraftbase Frontend Engineer assignment.

**Live:** https://kraftbase-frontend-assignment-one.vercel.app/

## Setup

```bash
git clone https://github.com/shubhamsinghbundela/kraftbase-frontend-assignment.git
cd kraftbase-frontend-assignment
npm install
npm run dev
```

Open http://localhost:5173 in your browser.
